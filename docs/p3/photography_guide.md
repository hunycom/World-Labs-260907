# Phase 3 실사 다시점 촬영 프로토콜 및 가이드 (P3-00 Task 2)
(Multi-view Photography Protocol for 3DGS Reconstruction & Marble Input)

---

## 1. 촬영 대상 및 수량 규격

| 구분 | 촬영 대상 | 최소 수량 | 촬영 궤적 및 간격 | 권장 피사체 조건 |
|---|---|---|---|---|
| **세트 A (소품)** | 실내 단일 물체 | **32장** | • 수평 원형 궤도 24장 (반경 1.0 m, 15° 간격)<br>• 상단 45° 고각 궤도 8장 (45° 간격) | 30×30 cm 이상 크기, 무광(matte), 질감/텍스처 풍부 (투명, 거울, 고광택 금속, 민무늬 플라스틱 배제) |
| **세트 B (장면)** | 산업 창고/통로 | **40장** | • 통로 전진 지그재그 보행 40장<br>• 프레임 간 시각 중첩도 $\ge 60\%$ | 팔레트 랙, 기계, 설비 등 기하학적 특징이 뚜렷한 실내 공간 |

## 2. 스마트폰 카메라 필수 촬영 세팅

1. **노출 및 초점 고정 (AE/AF Lock)**:
   - 피사체 중심부를 길게 눌러(Long-press) **노출/초점 고정(AE/AF Lock)**을 반드시 활성화합니다. 프레임마다 밝기나 초점이 바뀌면 재구성 손실이 급증합니다.
2. **배율 고정**:
   - 디지털 줌을 절대 사용하지 않고 **기본 1.0x 광학 렌즈**만 사용합니다.
3. **후처리 왜곡 비활성화**:
   - 자동 야간 모드, 왜곡 보정 필터, 뷰티 모드, 인물 사진(심도 블러) 모드를 끕니다.
4. **EXIF 메타데이터 보존**:
   - 메신저(카카오톡 등) 전송 시 EXIF 초점거리(Focal Length)가 손실되므로, **USB 케이블 직결 전송** 또는 **클라우드 원본 파일(ZIP) 전송**을 사용해야 합니다.
5. **모션 블러(흔들림) 방지**:
   - 걸으면서 촬영하지 않고, **발을 멈추고 호흡을 고른 상태에서 정지 촬영**합니다. (흔들림 프레임 $\le 10\%$ 판정 기준 적용).
6. **절대 척도 기준물(Scale Reference) 필수 배치 (스케일 모호성 해소)**:
   - 다시점 재구성 모델은 절대 크기를 알 수 없으므로, **치수가 알려진 기준물(A4 용지 297×210 mm 또는 30 cm 자)**을 피사체 바로 옆(바닥면)에 놓고 **최소 3장 이상의 사진에 기준물 전체가 명확히 포함**되도록 촬영해야 합니다. (P3-03 "재구성 척도 오차 < 2%" 검증 근거).

## 3. 촬영 궤적 다이어그램

### 3.1 세트 A: 실내 소품 원형 궤도 (32장)

```text
                  [Top View: 360° Circular Orbit]

                           (01) 0°
                    (24)             (02)
                (23)                     (03)
             (22)                           (04) 45°
           (21)                               (05)
          (20)                                 (06)
   270°   (19)            [ OBJECT ]           (07)   90°
          (18)           (30x30cm+)            (08)
           (17)                               (09)
             (16)                           (10)
                (15)                     (11) 135°
                    (14)             (12)
                           (13) 180°

   * 1층 (지상 0.8~1.0m 수평): #01 ~ #24 (15° 간격 24장)
   * 2층 (상단 45° 내려다보기): #25 ~ #32 (45° 간격 8장)
```

### 3.2 세트 B: 산업 창고/통로 전진 궤적 (40장)

```text
                  [Corridor Walkthrough: Overlap >= 60%]

       [ Rack A ]                                  [ Rack B ]
   ==============================================================
     (01) 좌측 정면 바라보기  -->  (02) 우측 정면 바라보기
                   \                  /
                    (03) 중앙 1m 전진 (04) 중앙 상단
                   /                  \
     (05) 좌측 랙 디테일     <--   (06) 우측 랙 디테일
   ==============================================================
   * 전진 간격: 발걸음 1보(약 0.6m)당 1~2컷 촬영
   * 항상 이전 컷의 시야 60% 이상이 다음 컷에 포함되도록 화각 유지
```

## 4. 파일 저장 및 디렉토리 구조

촬영된 원본 JPEG/HEIC 이미지는 아래 경로에 배치합니다:

```text
assets/p3/
├── capture_object/       # 실내 소품 32장 (obj_01.jpg ~ obj_32.jpg)
└── capture_scene/        # 창고 통로 40장 (scene_01.jpg ~ scene_40.jpg)
```

이미지 배치 완료 후 터미널에서 다음 명령어로 무결성 원장을 생성합니다:
```bash
sha256sum assets/p3/capture_object/*.jpg assets/p3/capture_scene/*.jpg > docs/p3/asset_ledger_p3.sha256
```
