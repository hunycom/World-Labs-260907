## 5. 감사관 사양 정정 3건

### 5.1 임펄스 크기 상향 정정 ($2.0\text{ m/s} \to 2.5\text{ m/s}$)
- **정정 사유**: 초기 P2-02 규격에서 $I = m \times 2.0\text{ m/s}$ 부여 시, $45^\circ$ 상향 임펄스($I_2$)의 초기 수직 속도는 $v_{0,y} = 2.0 / \sqrt{2} \approx 1.4142\text{ m/s}$였음. 연속 시간 이론 최고점 변위는 $v^2/(2g) = 1.4142^2 / 19.62 = 0.1019\text{ m}$이나, 60Hz 이산 시간 적분($dt = 1/60\text{ s}$) 및 선형 공기 감쇠($\gamma = 0.05$)가 1스텝부터 누적되어 실측 $\Delta y$가 $0.098\text{ m}$로 측정되어 기준선($\ge 0.10\text{ m}$)에 미달함.
- **정정 내용**: 감사관이 지시서 `EXE-260905-P2-03`을 통해 임펄스 크기를 $I = m \times 2.5\text{ m/s}$로 상향 조정하여 이산화 오차 및 감쇠 마진을 확보함.

### 5.2 자유비행 초기 각도 측정식 정정
- **정정 사유**: 투척 1스텝 직후($t=1$) 속도 벡터 $v_1$을 단순 관측할 경우, 바닥면 쿨롱 마찰 및 지면 반력, 중력 가속도($-9.81 \times 1/60 = -0.1635\text{ m/s}$)가 동시에 작용하여 초기 임펄스 방향과 인공적 각도 편차가 발생함.
- **정정 내용**: 감사관이 지시서 `EXE-260905-P2-03`을 통해 지면 및 인접 강체와의 접촉 이벤트 수가 0건인 첫 번째 자유비행 스텝($v_{\text{free\_flight}}$)을 검출하고, 해당 스텝의 속도 벡터를 기준으로 기준 임펄스 방향과의 각도 편차를 산출하도록 판정식을 정정함.

### 5.3 Task 3 분해율 50% 분리 명시
- **정정 사유**: P2-02 지시서에서 Task 1의 분해율을 15%로 축소 변경하면서 Task 3의 분해율 조건을 명시하지 않아, Task 3가 부품 간 물리적 접촉이 존재하는 분해율 15% 상태에서 구동되어 5건의 부품 간 충돌 FAIL이 발생함.
- **정정 내용**: 감사관이 지시서 `EXE-260905-P2-04`를 통해 Task 1은 낙하 접촉 시험용 분해율 15%, Task 3는 부품 간 간섭 없는 자유 투척 시험용 분해율 50%(2.0초 정착 대기 후 투척)로 시험 조건을 명확히 분리 규정함.

## 6. INC-01: 해시 생성 사건 전말 및 재발 방지 대책

### 6.1 사건 경위
Phase 2 1회차 시험(P2-01) 수행 직후 작성된 walkthrough 문서 및 결과 보고에서, 7개 자산 파일 원장(`docs/asset_ledger.sha256`)의 SHA256 해시값이 실제 파일 시스템의 해시값이 아닌 모델이 임의로 생성한 가상 문자열(`3bbda16c...`, `c40693a1...` 등)로 기재되어 감사관의 대조 검산에서 적발됨.

### 6.2 원인 분석 및 소명
셸 환경에서 `sha256sum` 명령어를 실행하여 표준 출력을 그대로 파일에 파싱하는 절차를 생략하고, 보고서 양식 작성 시 임의 문자열을 기입한 모델 생성 결함(Hallucination)으로 확인됨. 실제 모델 파일 자체의 변조는 없었으나 보고 무결성을 심각하게 훼손함.

### 6.3 재발 방지 확약 조치
1. **원문 출력 포인터 의무화**: 모든 해시 검증 시 터미널 표준 출력을 직접 파일(`docs/p2-06_terminal.txt`)로 캡처하여 동봉함.
2. **원장 자동 대조 검증**: 커밋 전 `sha256sum -c docs/asset_ledger.sha256` 명령어를 자동 실행하여 7개 파일 전수 성공을 확인하고 CLI 로그를 첨부함.
3. **무가공 원칙**: 해시 문자열 및 벤치마크 계측치에 대한 축약, 가공, 임의 반올림을 전면 금지하고 원본 JSON 파일 및 sha256sum 출력을 1:1 대조함.

## 7. 이월 항목 (Phase 3 및 프로덕션 과제)

1. **실 하드웨어 GPU FPS 계측 이월**:
   - 현재 벤치마크 환경은 Xvfb(`:11.0`) 가상 버퍼 환경의 LLVMpipe 소프트웨어 래스터라이저로 제한되어 WebGL 픽킹 버퍼 렌더와 WASM 물리 시뮬레이션 동시 실행 시 평균 28.7 ~ 29.88 FPS를 기록함. 하드웨어 가속 GPU 환경에서의 60 FPS 달성 여부는 Phase 3 실기 시험으로 이월함.
2. **픽킹 프록시 BBox $p_5 \sim p_{95}$ 정밀화**:
   - 현재 AABB 프록시 박스는 외곽 노이즈를 배제한 $p_5 \sim p_{95}$ 분위수로 구성되어 있으나, 회전된 부품(날개 및 머리)에서 기하학적 여백 또는 국소 중첩이 존재함. OBB(Oriented Bounding Box) 또는 Convex Hull 기반 충돌 프록시 정밀화는 Phase 3로 이월함.
3. **정면 뷰($0^\circ$) 픽킹 76% 한계 개선**:
   - 3DGS 가우시안 타원체 정면 투영 시 발생하는 깊이 모호성 및 부품 간 가림(occlusion)으로 인해 정면 뷰 정확도가 76%로 측정됨. 기본 카메라 시점을 45° 쿼터 뷰로 동결하여 운용하며, 정면 뷰 깊이 버퍼 해상도 향상은 Phase 3 파이프라인으로 이월함.
4. **Task 3 #04 (`head` I1) 투척 충돌의 설계상 허용**:
   - head 부품에 후방 임펄스 $I_1=(0,0,-1)$ 인가 시, 50% 분해 위치에서도 head 후방에 위치한 body 전면 돌출부와 $0.3458\text{ m}$ 비행 지점에서 강체 충돌이 발생함. 이는 기하학적 배치상 자연스러운 물리 현상으로, 설계상 허용 예외(ALLOWABLE EXCEPTION)로 확정 승인됨.
