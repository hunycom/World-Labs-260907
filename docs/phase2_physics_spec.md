## 1. 개요 및 동결 선언 (Parameter Freeze Declaration)

System 2 감사관(Auditor) 및 허상훈 Principal의 지시서 `EXE-260905-P2-01`에 따라, 대상 브랜치 `feature/phase2-physics`에서 구동되는 Rapier3D(WASM) 물리 시뮬레이션의 모든 기하학적·역학적 파라미터를 **시험 실행 전 완전 동결(FROZEN)**합니다.

본 규격은 PLY 점군 실측 $p_5 \sim p_{95}$ 퍼센타일과 밀도 비례 공식($\rho = 500\text{ kg/m}^3$)으로부터 100% 결정론적으로 계산되었으며, 시험셋 맞춤형 사후 튜닝을 원천 배제합니다.

## 3. 5대 부품 충돌체 및 질량 공식 유도 명세

### 유도 공식
1. **$p_5 \sim p_{95}$ 바운딩 박스 치수**:
   $$\text{Size} = p_{95}(X, Y, Z) - p_5(X, Y, Z)$$
2. **로컬 충돌체 중심 오프셋**:
   $$\text{Center} = \frac{p_{95}(X, Y, Z) + p_5(X, Y, Z)}{2}$$
3. **체적 및 질량 산출**:
   $$V = \text{Size}_x \times \text{Size}_y \times \text{Size}_z, \quad m = \rho \times V \quad (\rho = 500.0\text{ kg/m}^3)$$
4. **관성 모멘트 텐서 ($\mathbf{I}$)**:
   직육면체 표준 관성 텐서 ($I_{xx} = \frac{1}{12}m(H^2 + D^2), I_{yy} = \frac{1}{12}m(W^2 + D^2), I_{zz} = \frac{1}{12}m(W^2 + H^2)$)를 Rapier3D가 강체 질량 중심에 자동 계산하여 바인딩.

## 4. 시험 시나리오 규격 (Test Scenario Specifications)

### Task 1 — 자유낙하 접지 시험
- **초기 상태**: 분해 50% 위치에서 각 부품 $y$ 좌표 $+1.0\text{ m}$ 상승.
- **섭동**: 시드 7, 21, 42를 기반으로 Euler 각 $\pm 2^\circ$ 미세 섭동 부여.
- **시간**: 5.0초 (300 물리 틱).
- **판정 기준 (15/15 전수)**:
  - (a) $t = 5.0\text{ s}$에서 충돌체 최저점 $y \in [-0.01, +0.02]\text{ m}$
  - (b) $t = 5.0\text{ s}$에서 $|v| < 0.01\text{ m/s}$, $|\omega| < 0.05\text{ rad/s}$
  - (c) 관입 깊이 $< 0.02\text{ m}$
  - (d) $|x|, |z| < 3.0\text{ m}$ (이탈 부재)

### Task 2 — 성능 프로파일
- **조건**: Task 1 시드 42 시행 중 10초 프레임타임 측정 (단일 탭 포그라운드).
- **판정 기준**: $p95 \le 64\text{ ms}$, `filteredCount` 보존.

### Task 3 — 투척 인터랙션 정합
- **조건**: 5부품 $\times$ 3임펄스($I_1=(0,0,-3), I_2=(2,2,0), I_3=(-2,3,-1)\text{ N}\cdot\text{s}$) = 15건.
- **선택 좌표**: 부품 투영 `bbox_center` $+ (+20, -20)\text{ px}$.
- **판정 기준**: 선택 부품 = 목표 부품 AND 이동 부품 = 목표 부품 AND 초기 속도 벡터 각도 $\le 15^\circ$ AND 5초 내 정착 AND 이탈 없음 ($\ge 14/15$).
