> **차세대 산업용 공간 지능(Spatial Intelligence) & 3D Gaussian Splatting 디지털 트윈 런타임 플랫폼**

## 🏛️ 1. 시스템 개요 및 3대 코어 엔진 아키텍처

`spark_spatial_os`는 단순한 정적 3D 뷰어(Trellis, Tripo 등)의 한계를 극복하고, **NVIDIA RTX 4090 (24GB VRAM) 단일 로컬 워크스테이션**에서 공간 지능의 **3대 핵심 엔진(신경계, 두뇌, 물리 엔진)**과 **4단계 자율 폐쇄 루프(Closed-Loop)**를 100% 로컬에서 완벽하게 구동하는 독립형 공간 지능 운영체제입니다.

```
                                  ┌────────────────────────────────────────────────────────┐
                                  │           🧠 [두뇌 - The Brain]                         │
                                  │   • VLM 3D 지각 & 사물 쓰임새(Affordance) 0.01mm 분석   │
                                  │   • 자연어 프롬프트(LLM) ➔ 3D 공간 제어 신호 변환       │
                                  │   • XAI 설명가능한 인과 추론(Causality Engine)         │
                                  └───────────────────────────┬────────────────────────────┘
                                                              │ (자연어 명령 & 의미론적 좌표 전달)
                                                              ▼
┌────────────────────────────────────────────────────────┐    │    ┌────────────────────────────────────────────────────────┐
│           ⚡ [신경계 - The Nervous System]              │    │    │           ⚙️ [물리 엔진 - The Physics Engine]          │
│   • Rust WASM Radix Sort (100만 점 1ms 백그라운드 정렬) │◄───┴───►│   • Dyno 프로그래머블 노드 셰이더 (SDF 파동/변형)     │
│   • SPZ 95% 초압축 & PackedSplats GPU 메모리 버퍼       │         │   • PINN 열역학/유체역학 미분방정식 실시간 예측        │
│   • 현실 IoT 센서(온도/진동) 60FPS 실시간 동기화       │         │   • Three.js 6축 로봇 팔 & 물리 충돌(Raycast) 합성     │
└────────────────────────────────────────────────────────┘         └────────────────────────────────────────────────────────┘
```

## ⚡ 2. 3대 엔진 핵심 명세

### 1) ⚡ 신경계 (The Nervous System)
- **Rust WebAssembly Radix Sort**: 100만 개 이상의 3D 가우시안 타원체를 메인 스레드 부하 없이 1ms 만에 초고속 깊이 정렬.
- **SPZ 95% 초압축 & PackedSplats**: 500MB PLY를 20MB 이하로 압축하여 GPU 메모리에 16/32비트 고정밀 텍스처 버퍼로 상주.
- **실시간 IoT 텔레메트리 텐서 반응**: 설비 과열 및 이상 진동 발생 시 3DGS 가우시안 타원체 색상/불투명도 실시간 변색 발광.

### 2) 🧠 두뇌 (The Brain)
- **VLM 3D 공간 지각 & 어포던스 (0.01mm)**: 모터 회전축, 부품 결합 틈새(0.01mm)의 위치와 쓰임새를 시각-언어 의미론적으로 파악.
- **AI 3D Copilot 자연어 프롬프트 인터페이스**: 사용자의 일상 언어 명령을 해석하여 3D 기계 관절 및 제어 신호로 변환.
- **설명 가능한 AI (XAI) 인과 추론 스트림**: 모든 상태 변화의 근거와 대안, 물리적 인과 관계를 실시간 원장(Ledger)으로 기록.

### 3) ⚙️ 물리 엔진 (The Physics Engine)
- **Dyno 프로그래머블 셰이더 & SDF 파동**: 수백만 개의 점군을 WebGL 셰이더 코딩 없이 실시간으로 파동, 진동, 변위 시뮬레이션.
- **PINN (물리 정보 신경망) 열역학 샌드박스**: 나비에-스토크스 및 열전도 미분방정식을 기반으로 **t+2.4초 후의 화재/단선을 사전 예측**.
- **Three.js 6축 다관절 로봇 Kinematics 결합**: 실사 3DGS 공간과 일반 3D 폴리곤 로봇 팔의 Z-Buffer 하이브리드 깊이 융합.

## 💻 3. 로컬 RTX 4090 (24GB VRAM) 자원 배분표

| 엔진 구분 | 탑재 기술 스택 | VRAM 점유량 | 역할 및 성능 |
| :--- | :--- | :--- | :--- |
| **⚡ 신경계** | Spark.js 2.1.0 + WebGL2 / WebGPU | **약 2.5 GB** | 3DGS 실사 씬 60~120 FPS 렌더링 및 Rust WASM 정렬 |
| **🧠 두 뇌** | Qwen2.5-VL-7B (INT4) / Ollama | **약 7.5 GB** | 3D 바운딩 박스 지각, 자연어 의도 파싱, XAI 인과 로그 |
| **⚙️ 물리 엔진** | PyTorch PINN + Dyno Shader | **약 3.5 GB** | 열전도 미분방정식 샌드박스 예측 및 6축 로봇 기구학 연산 |
| **시스템 여유 버퍼** | CUDA 텐서 버퍼 & LoD 스트리밍 | **약 10.5 GB** | 초대형 공장 씬 스트리밍 및 고속 연산 여유 마진 |
| **합계** | **단일 RTX 4090 올인원 구동** | **총 13.5 / 24 GB** | **추가 하드웨어 구매 없이 100% 로컬 자율 구동 가능** |

## 🚀 4. 빠른 시작 가이드 (Quick Start)

### 1) 로컬 Edge 서버 실행 (Python)
```bash
cd spark_spatial_os
python server.py
```
- 브라우저 접속: `http://localhost:8088`

### 2) 자율 테스트 하네스 검증 (15개 전수 검사)
```bash
python harness_test.py
```
